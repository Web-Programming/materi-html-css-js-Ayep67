## Website Informasi Gempa BMKG

  1. https://data.bmkg.go.id/DataMKG/TEWS/autogempa.json
  2. https://data.bmkg.go.id/DataMKG/TEWS/gempaterkini.json

- Gunakan data dari API 1 untuk menampilkan informasi gempa terbaru
- Gunakan data dari API 2 untuk menampilkan informasi 15 gempa terakhir yang terjadi
- Gunakan Bootstrap dan tampilkan lokasi gempa pada maps (opsional)
